# 구매요청 입력 양식

기본 사용 방식은 대화입니다. `필요한 정보를 나에게 물어보면서 구매요청서를 만들어줘`라고 시작하면 빠진 항목을 차례로 질문합니다. 아래 양식 전체를 미리 채울 필요는 없습니다.

한 번에 전달하려면 아는 항목만 채우고 견적서·장바구니 캡처를 함께 제공하세요. 모르는 항목은 `모름`으로 두면 확인할 내용을 안내합니다. 소속·요청자·직급·직책·사용장소·관리부서·결재선은 사용자별로 확인하며 임의로 정하지 않습니다.

```text
$hct-purchase-request 아래 정보와 첨부자료로 구매요청서 초안을 만들어줘.

요청자 소속 부서/팀/파트:
요청부서/ERP 구매그룹(알면):
요청자 성명:
요청자 직급:
요청자 직책(있으면):
요청일:
결제방식: 세금계산서 후 입금 / 구매팀 신용카드 / 기타·미정
거래처(카드 건은 실제 사이트/판매처):
견적 통화:
희망 납기일:
실제 납품 위치(동):
사용장소(동/층/실):
관리부서:
구매목적:
상세사유(교체/증설/수량 근거 등):

품목별로 반복:
- 제품명/모델:
- 규격/옵션:
- 수량/단위:
- 개당 단가:
- 단가 VAT 포함/별도:
- 배송비/운임/기타비용(이미 단가에 포함됐는지도 표시):
- 할인 및 최종 결제금액:
- 판매 목적 여부:
- 예상 사용기간/수리·관리 가능 여부:
- ERP 품목코드(알면):
- 자산이면 예산단위/예산계정(알면):
- 품목별 사이트/판매처·납품 위치·납기(서로 다르면):

첨부자료(그룹웨어 결재창에 등록할 증빙):
현재 단계: 새 초안 / PRQ 저장 / 상신 / 종결 / 반려
실제 MRS(PRQ) 번호(발급받았다면):
원하는 결과: 대화에서 복사할 초안 / 지정 파일 형식

상신까지 요청하는 경우에만:
- 결재선(순서별 이름·직급·직책, 소속은 알면 함께):
- 메일 알림: 켜기 / 끄기
- 공개 범위: 공개 / 비공개 / 확인 필요
```

## 짧은 사용 예시

```text
$hct-purchase-request 견적서 기준으로 구매요청서 만들어줘.
연구시험팀의 시험 연결용 RF 어댑터 2개야.
구매팀 카드로 결제하며 개당 22,000원(VAT 포함), 배송비 3,000원이야.
1동으로 납품받고 1동 2층 시험실에서 사용할 거야.
관리부서는 연구시험팀, 희망 납기는 2026-10-20이야.
```

ERP 품목코드나 예산계정은 예시에서 복사하지 말고 실제 등록값을 확인하세요. 카드·결제·배송 정보가 견적서와 다르면 그 차이도 함께 알려주세요.
